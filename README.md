## The entry

> I fed the parking meter two dollars and it expired in ten minutes, so now I'm convinced it's a slot machine that pays out in fines.

A single 131-character line. The setup is a mundane frustration — a meter
that eats your money and expires almost immediately — and the twist reframes
the meter as a casino slot machine whose only payout is a fine. Nothing in
the line is wasted: every clause earns its place, and the joke stands alone
without a title, setup, or explanation.

## How to run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (creating `/output` if needed),
then reads it back and asserts it is byte-identical to the entry in
`main.py`, with no trailing newline. `main.py` uses only the Python standard
library (`os`, `sys`) and takes no arguments.
